機関リポジトリメタデータ 簡易検索サービス（サンプル）

JAIRO Cloud メタデータ取得・検索ツールで作成した簡易検索サービスのサンプルです。国際農研機関リポジトリのデータを使用しています。

IRDBから取得した機関リポジトリのメタデータを検索します。Wayback Machine に PDF ファイルが保存されていて、CC ライセンスであることを確認できたものだけ、PDF へのリンクを表示します。

タイトル、刊行物名、レコード番号、ファイル名などから検索します。空白で区切ると、すべてを含むものだけに絞り込みます。全角・半角と英字の大小は区別しません。

PDF は、表示されている CC ライセンスの条件（クレジットの表示、非営利、改変禁止など）に従って利用してください。正確なライセンスは、IRDB または提供機関で確認してください。

PDF へのリンクは Internet Archive の Wayback Machine 上のファイルです。Internet Archive の利用条件にも従ってください。

「取得可」は、Wayback Machine に PDF の保存を確認できたことを示します。複数ファイルのうち一部だけが保存されている場合は区別できません。

ライセンスは、Wayback Machine に保存されたリポジトリのメタデータ（権利情報と、ファイルごとのライセンス種別）から判定しています。保存されたメタデータが古い場合や、保存されていない場合があります。「要確認」は、2つの情報が食い違うものです。

表示されているメタデータとリンクはデータ取得時点のものです。変更されている場合があります。
